# Selenium Automation Ruby Framework

# selenium automation framework made with Selenium Webdrivers, Ruby, RSpec

# tech stack
- Ruby
- Selenium Webdriver
- Chromedriver
- RSpec

# Framework Structre

- Pages/
- Locators/
- Spec/

# Setup

- Install Ruby
- Clone the repository
- Run: bundle install

# To run tests

- bundle exec rspec <spec_file_name>

# Features

- Page object model
- Explicit waits
- Locators Separated
- Reusable Driver setup

# Future enhancements

- Reporting tool attachment
